TableOS: A responsive tabletop.

Making physical miniatures interact with digital maps and live game effects.

PROJECT CONTEXT

Self-developed digital tabletop

Hardware input and browser-based interface

Related systems work ↗

A tabletop that responds to real pieces

MY ROLEPersonal hardware/software build
EVIDENCEFive miniatures trackedPrototype tested at the table

The challenge

Physical miniatures and digital tabletop maps don't automatically communicate. Keeping each character's identity stable while pieces move, and coordinating game effects in real time, created a practical interaction problem to solve.

What I built

  • Device integrationConnected an infrared touch frame through a Raspberry Pi input client to a Linux ThinkCentre running TableOS.
  • Contact stateDeveloped contact association and reconnection logic to maintain character identities as miniature positions change and during brief USB interruptions.
  • Live game effectsCreated browser-based tabletop controls for game effects and character-centered presentation.
  • Lighting & presentationExperimented with lighting cues and game-event presentation to make a physical group session more interactive.

What I've tested

Five player miniatures have been tracked simultaneously. In testing, a lifted miniature could be reassociated with its character when placed back down within roughly ten seconds. The input handling was also adjusted to preserve contacts across transient USB reconnections.

Why it matters

The project combines requirements thinking, hardware/software integration, state management, testing and interface design for real users. It demonstrates practical technical problem-solving, not measured commercial ROI or production-scale deployment.
