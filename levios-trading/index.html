CHRONOLOGICAL RESEARCH / PAST-ONLY SELECTION

Walk-forward testing

NO BROKER ORDERS

Use the current price source and execution-cost settings. Three expanding training periods each select the best training excess return from a fixed 5/20, 10/30, or 20/50-day moving-average grid. Each selected rule is evaluated only on the next, non-overlapping period.

Requires at least 150 historical closes. This is historical simulation, not fresh forward-paper results.

Each fold is an independent simulation with carried-in position state, not a stitched live-trading portfolio. No orders or future predictions are generated.

Divides the existing evaluation period into three consecutive, non-overlapping windows. Each window compares strategy performance with buy-and-hold over those same dates. No retraining or independent blind test occurs.
